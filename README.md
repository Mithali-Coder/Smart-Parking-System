# Smart Parking System 🚗

An IoT-based Smart Parking System that helps users find available parking spaces in real time. The system uses sensors to detect vehicle occupancy and updates slot status automatically. Parking availability is displayed through a user-friendly dashboard, reducing search time and traffic congestion. The project improves parking space utilization and enhances the overall parking experience. Built using IoT hardware and web technologies for efficient parking management.
